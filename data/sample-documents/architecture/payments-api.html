Architecture: payments-api

payments-api is owned by team-payments. Its availability target is 99.9% and its latency objective is p99 below 300 ms.

Components

  • LedgerReconciler compares our ledger with the payment provider's settlement file every hour and opens a ticket for any mismatch.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The LedgerReconciler keeps the hot path short and moves slow work to the background.
