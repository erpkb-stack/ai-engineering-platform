Architecture: cart-api

cart-api is owned by team-cart. Its availability target is 99.9% and its latency objective is p99 below 150 ms.

Components

  • QuoteSnapshotter freezes the price shown to the customer for 10 minutes so the charged amount matches the displayed amount.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The QuoteSnapshotter keeps the hot path short and moves slow work to the background.
