Architecture: ledger-worker

ledger-worker is owned by team-ledger. Its availability target is 99.9% and its latency objective is p99 below 300 ms.

Components

  • SynonymExpander adds known synonyms to the user's search terms before the index is queried.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The SynonymExpander keeps the hot path short and moves slow work to the background.
