Architecture: shipping-api

shipping-api is owned by team-shipping. Its availability target is 99.9% and its latency objective is p99 below 200 ms.

Components

  • RiskScoreCache keeps the last risk score per account for 60 seconds so repeated checks do not call the model again.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The RiskScoreCache keeps the hot path short and moves slow work to the background.
