Architecture: notifications-worker

notifications-worker is owned by team-notifications. Its availability target is 99.9% and its latency objective is p99 below 300 ms.

Components

  • InvoiceNumberAllocator hands out gap-free invoice numbers per country using a database sequence per region.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The InvoiceNumberAllocator keeps the hot path short and moves slow work to the background.
