Architecture: inventory-api

inventory-api is owned by team-inventory. Its availability target is 99.9% and its latency objective is p99 below 250 ms.

Components

  • StockReservationSaga reserves stock in three steps and releases it automatically after 15 minutes if payment does not complete.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The StockReservationSaga keeps the hot path short and moves slow work to the background.
