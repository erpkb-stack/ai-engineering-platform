Architecture: pricing-api

pricing-api is owned by team-pricing. Its availability target is 99.9% and its latency objective is p99 below 250 ms.

Components

  • DigestBatcher groups notifications per user into one message every 5 minutes to avoid spamming.
  • API layer validates requests and enforces authentication.
  • Persistence PostgreSQL with one schema per service.

Design decisions

We chose this approach because the simpler alternative failed during load tests. The DigestBatcher keeps the hot path short and moves slow work to the background.
